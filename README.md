# Rite

Daily rites. Lasting streaks.

A local-first habit tracker: check-offs, week and month calendars, streaks, reminders, study/sleep modes, and self-control **Guards** (app lists, hours, daily caps, places). Data stays in the browser. No account.

## Download

Android debug APK (sideload, not Play Store signed):

**[Rite-debug.apk](https://github.com/Maya920tu/Rite/releases/latest/download/Rite-debug.apk)** — also on the [Releases](https://github.com/Maya920tu/Rite/releases) sidebar.

iOS: no IPA from this repo. Needs a Mac, Xcode, and an Apple Developer account (`native/SHIP.md`).


```bash
npm install
npm run dev
```

## What it is

- **Web app / PWA** you can install to the home screen and use offline after the first visit.
- **Capacitor shell** for a future App Store / Play Store build (`capacitor.config.ts`, `native/SHIP.md`). This repo does not include generated `android/` or `ios/` projects.

## Self-control (honest)

Rite can pin itself (Android app) and run a strict study timer. It **cannot** hide Instagram.

| | Web / PWA | Android app | iPhone app |
|---|---|---|---|
| Habits, streaks, offline | Yes | Yes | Yes |
| Pin Rite to the screen | Fullscreen | Screen pinning | Guided Access / Focus |
| Block other apps | No | Digital Wellbeing Focus | Screen Time / Focus |

Set lists and schedules in **Self-control → Guards**. Turn on the matching Focus / Screen Time / Digital Wellbeing rule on the phone. Copy the list from the Phone tab.
